Source Code framework/validators/CDefaultValueValidator.php
CDefaultValueValidator sets the attributes with the specified value. It does not do validation but rather allows setting a default value at the same time validation is performed. Usually this happens when calling either $model->validate() or $model->save().

        $object->$attribute=$this->value;
    else
    {
        $value=$object->$attribute;
        if($value===null || $value==='')
            $object->$attribute=$this->value;
